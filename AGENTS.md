# AiTripBuddy

MVP-конструктор горнолыжной поездки: маршрут на графе, отели, скипасс, питание и смета.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Vite dev-сервер на `http://localhost:5173` |
| `npm run build` | `vue-tsc --noEmit` + production-сборка |
| `npm run typecheck` | проверка типов без сборки |
| `npm run lint` | ESLint (flat config, TS + Vue) |
| `npm test` | Vitest, юнит-тесты в `tests/` |
| `npm run test:watch` | Vitest в watch-режиме |

Перед завершением задачи запускайте `npm run typecheck && npm run lint && npm test`.

## Структура

- `src/types.ts` — доменные типы (`Trip`, `Stop`, `RouteLink`, `Meals`).
- `src/data/` — справочники: города/аэропорты, курорты, связки «курорт ↔ аэропорт», цены питания.
- `src/lib/` — чистые функции: `costs`, `currency`, `geo`, `format`, `schedule` (гант), `compare` (метрики), `share` (ссылки).
- `src/stores/` — реактивные сторы: текущая поездка, библиотека сохранённых, импорт из ссылки.
- `src/components/` — граф, гант, карта, смета, модалки (поездки, сравнение), узлы маршрута.
- `src/styles/` — `main.css` только импортирует модули (`base`, `layout`, `timeline`, …).
- `tests/` — Vitest: стоимость, геометрия/валюты, расписание, сравнение, шаринг, справочники.
- `docs/DEPLOY.md` — GitHub Pages, формат ссылок, сравнение.
- `docs/AGENTS-HARNESS.md` — как агенту работать в репозитории: порядок чтения, инварианты, гейт, границы.
- `public/roadmap.html` — интерактивный роадмап: узлы майлстонов, клик разворачивает описание, чек-лист и беклог с сохранением галочек.
- `.github/workflows/deploy.yml` — CI: typecheck → lint → test → build → Pages.

## Правила

- Все денежные суммы хранятся в валюте поездки; курс — `src/lib/currency.ts`, единственный источник правды.
- Числа считает код, не LLM: `computeCosts`, `foodPerDay`, `buildSchedule`, `tripMetrics` — чистые функции с тестами.
- Любые внешние данные нормализуются через `normalizeTrip()` перед использованием (localStorage, библиотека, ссылка).
- Даты отелей — `checkIn` (`YYYY-MM-DD`), у участков — `date`/`time`. Гант строит строки и для отелей, и для событий перелёта/трансфера; без дат дни нумеруются условно.
- Узел отеля переключается между «Курорт» и «Город» (`placeKind`), чтобы вернуться с курорта в город перед вылетом.
- Справочники связные: `tests/data.test.ts` проверяет, что у каждого курорта есть существующий аэропорт и нет дублей кодов.
- Ссылки на наборы — `#trips=<code>` (`src/lib/share.ts`), данные только в хэше, без бэкенда.
- Записи в localStorage дебаунсятся (400 мс) и сбрасываются на `beforeunload`/`pagehide`.
- Leaflet подгружается лениво (`defineAsyncComponent`), чтобы не раздувать основной бандл.
- Сборка переносимая (`base: './'`), публикуется на GitHub Pages workflow-ом.
## Гид по курорту и 3D-карта

- `src/data/resort-guides.ts` — рекомендации, части курорта (цены скипасса, трассы по сложности, подъёмники) и реальные координаты базы/вершины. Гиды: Нисеко, Хакуба, Красная Поляна, Роза Хутор, Гудаури, Местиа, Шерегеш, Красное Озеро, Туутари Парк, Майрхофен. Валюты гидов: RUB, EUR, GEL, JPY.
- `src/components/ResortCatalog.vue` — каталог всех курортов: поиск по названию/региону/стране, фильтры по стране и месяцу сезона, «только с гидом», кнопка «Посмотреть гид».
- `src/data/resort-season.ts` — ориентировочные месяцы катания по странам (Хоккайдо выделен).
- `src/components/ResortGuideModal.vue` — большое окно гида: слева 3D-карта, справа рекомендации, скипассы по частям, сложность и советы.
- `src/components/ResortScene3D.vue` — MapLibre GL с 3D-рельефом, переключателем 3D/сверху и линейкой расстояний: OSM-тайлы + raster-dem (Terrarium), наклон 62°, трассы цветом по сложности, подъёмники пунктиром, нумерованные пины частей курорта.
- Требуется WebGL; при его отсутствии показывается заглушка. Тайлы и DEM грузятся из сети, поэтому гид не работает полностью офлайн.
- MapLibre подключён лениво (отдельный чанк ~300 КБ gzip) и исключён из `optimizeDeps` в `vite.config.ts`, иначе ломается worker в dev.

## Известные подводные камни

- MapLibre worker: сборка ищет `maplibre-gl-worker.mjs` рядом с чанком и падает с «Worker failed to load». Поэтому в `ResortScene3D.vue` воркер подключается явно: `import workerUrl from 'maplibre-gl/dist/maplibre-gl-worker.mjs?url'` + `setWorkerUrl(workerUrl)`.
- Для 3D-рельефа и hillshade нужны разные raster-dem источники (`dem` и `hillshadeDem`), иначе MapLibre ругается и качество падает.
- `optimizeDeps.exclude: ['maplibre-gl']` обязателен: иначе Vite ломает worker в dev.
